Plan a fictional visit

The page has enough content to test scroll locking. Scroll here, open the drawer and close it. Your reading position should return to the same place.

No address, opening hours or real service is represented by this example. Its purpose is to make navigation behaviour easy to inspect.

Try the keyboard sequence

  1. Reach Menu with Tab. Enter and Space should both open the drawer.
  2. Focus starts on Close. Tab and Shift+Tab stay inside the modal.
  3. Escape closes the drawer and returns focus to Menu.
  4. Select a navigation item. The drawer closes and the destination receives focus.
  5. Reload with JavaScript disabled. The ordinary navigation links remain available.

Local interaction log

The log records control IDs and event descriptions. It does not record typed text, store data or send requests.
